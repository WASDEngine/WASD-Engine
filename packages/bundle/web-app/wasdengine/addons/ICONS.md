# Add-on icons

The Add-ons dialog shows these icons beside the catalog's add-ons. Each one is the add-on's own image, an icon from Blender's source for Rigify and A.N.T. Landscape, or an icon from [Lucide](https://lucide.dev) for the add-ons that WASD Engine wrote, whose names begin with WASD; it was downloaded from the source below and is shared under the license and with the copyright line given there. A picture wider than 64 pixels is scaled down to 64, and the icons of the two Universal Animation Libraries are 64-pixel crops of their packs' preview images. Controller Icons shows one of the button pictures it ships. The Lucide icons, of version 1.77.0, have one change: their stroke color, which Lucide leaves to the page that shows an icon, is set to WASD Engine's purple, because the dialog draws each icon as a picture. Add-ons without an icon of their own that may be used here show a letter tile instead.
