# 联机多人游戏

[English](multiplayer.md) | 中文

用 WASD Engine 制作的游戏可以通过两种方式联机：玩家主机模式，由一名玩家的游戏免费为其他玩家当主机；或者专用服务器，由 WASD Engine 运行，按月付费。你可以直接告诉 agent（智能体），例如“把这个游戏做成最多 8 位好友的多人游戏”，它会在改动任何内容之前先说明两种模式及其费用。之后切换模式也不需要重写游戏的多人代码。

## 选择模式

| | 玩家主机 | 专用服务器 |
|---|---|---|
| 费用 | 免费 | 每台服务器按月计费，价格取决于规格 |
| 游戏运行在哪里 | 一名玩家的浏览器标签页中 | WASD Engine 位于俄勒冈的服务器上；没有人玩时休眠，有人加入时唤醒 |
| 玩家人数 | 2 到 8 人体验最好，最多 16 人 | 同时约 10 到约 100 人，取决于规格 |
| 所有人离开后 | 本局结束 | 世界会被保存，等待下一位玩家；开启 Always on 后，世界会持续运转 |
| 作弊 | 主机可以作弊 | 由服务器决定游戏中发生的一切 |
| 玩家的 IP 地址 | 其他玩家可见，除非连接经过中继 | 对其他玩家隐藏 |

两种模式下，每名玩家都要先用 WASD Engine 账号登录才能加入。

## 玩家主机游戏

一名玩家主持大厅，好友输入 6 位代码加入，或从公开大厅列表中选择。WASD Engine 负责让玩家彼此连接，并为网络无法直连的玩家中继连接，不收取费用。每款游戏每月的中继流量有一个合理使用额度；超出后，该游戏的中继停用到下个月，网络无法直连的玩家在此之前无法加入，agent 可以告诉你游戏的用量情况。主机必须让游戏的浏览器标签页保持打开并位于前台，因为浏览器会暂停隐藏的标签页，从而让所有人的游戏暂停。主机离开时，本局结束。主机可以永久移出某名玩家；主机的游戏未能及时连上的玩家则可以直接再次加入。

## 专用服务器

WASD Engine 运行你的游戏服务器版本，玩家随时都能加入。每种服务器规格都有月费，以及固定的 CPU、内存、每月带宽和存储空间；WASD Engine 网站和 agent 会显示当前的规格与价格。任何套餐的账号，只要有有效的付款方式，都可以购买服务器；在网站上确认购买之前，不会产生任何费用。如果 WASD Engine 为你的账号赠送了免费服务器，agent 和网站会把这些规格的服务器显示为免费，确认时也不需要绑卡。

- **带宽。** 服务器用掉每月带宽的 70%、90% 和 100% 时，你都会收到一封邮件。用到 100% 时，服务器会在本计费月的剩余时间内停止，额度重置后再自动启动；不会额外收费。
- **休眠。** 服务器连续 15 分钟没有玩家时，会保存世界并进入休眠；有玩家加入时会在几秒内唤醒，游戏可以告诉这名玩家服务器正在启动。休眠让价格保持在较低水平。如果你的世界需要在没有人玩时继续运转，请在网站的 Game servers 页面为这台服务器开启 **Always on**；Medium 及更大的规格提供这一选项。
- **备份。** 有玩家在线时服务器每小时备份一次，进入休眠时和每次更新前也会备份，备份保留 7 天。
- **更新。** 发布游戏的新版本会更新它的服务器，玩家会先收到一分钟的提醒。使用旧版本游戏的玩家无法加入运行新版本的服务器。
- **停止与删除。** 已停止的服务器仍会计费。删除服务器会结束计费，其数据在 7 天后删除。

## 玩家登录

玩家要先用 WASD Engine 账号登录才能加入。在 WASD Engine 网站的游戏页面上，由页面完成登录；从游戏自己的链接打开时，会弹出登录窗口。从 WASD Engine 游戏库启动的游戏使用应用的登录，在运行期间保持登录，最长一周；退出 WASD Engine 的登录后，一小时内随之失效。游戏能看到每名玩家的用户名和一个跨设备不变的玩家 id，永远看不到电子邮件地址或账号。
