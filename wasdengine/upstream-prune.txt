# wasdengine/sync-upstream.sh removes each tracked file that an entry names or
# that lies under an entry's directory, which also resolves the conflicts that
# upstream edits to those files cause. Fork-owned workflows and composite
# actions are named wasd-* and are never removed. One literal path or directory
# per line, relative to the repository root; wildcards are not expanded, and
# scripts/verify-md-links.ts reads the entries the same way. Blank lines and
# lines starting with # are ignored.
